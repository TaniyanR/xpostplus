# XPostPlus

X（旧Twitter）へ投稿する素材を取得・編集・管理する、管理者専用Webアプリです。Xへの自動投稿は行いません。

## 必要環境

- PHP 8.1以上
- MariaDB 10.4以上（MySQL 8系でも利用可能）
- PHP拡張: PDO MySQL、Sodium、SimpleXML、Fileinfo、mbstring
- FFmpeg（動画の切り抜き・圧縮・ミュート・縦横比変更に使用）
- HTTPS

Webサーバーの公開ディレクトリは `public` に設定してください。サブディレクトリ公開にも対応しています。

## 初回セットアップ

1. `rebuild/xpostplus-v1` のファイルをサーバーへ配置します。
2. MariaDB側で空のデータベースと接続ユーザーを作成します。
3. 環境変数 `APP_KEY` に32文字以上のランダム文字列を設定します。
4. ブラウザで開くと「MariaDB初期設定」が表示されます。
5. DB接続情報を入力し、「接続テストして保存」を押します。
6. 接続成功後、不足テーブル・カラム・インデックスが自動作成されます。SQLの手動実行は不要です。
7. 初期ID `admin`、初期パスワード `password` でログインします。

初回ログイン後のパスワード強制変更はありません。必要に応じて設定画面から変更できます。

DB設定は `storage/config/database.json` に保存されます。Webサーバーから `storage` を直接公開しないでください。

## 対応API

設定画面へ次の情報を保存してから接続テストを行います。認証情報は `APP_KEY` を使って暗号化してDBへ保存します。

- FANZA: API ID、アフィリエイトID
- DUGA: アプリケーションID、代理店ID、バナーID
- SOKUMIRU: API KEY、アフィリエイトID

各APIはキーワード検索、最大100件取得、取得素材の全選択・一括削除・個別削除、専用テンプレートによる投稿作成に対応します。

## 動画編集

公開されている動画ページURLまたはMP4 URLから動画を取得します。ログインやDRMが必要な動画は対象外です。1ファイルの上限は512MBです。

- 開始・終了時間による切り抜き
- 高画質／標準／容量優先
- ミュート
- 元の比率／16:9／1:1／9:16

編集処理にはサーバー上のFFmpegが必要です。

## 投稿管理

API・RSS・動画で作成した投稿を一か所で管理します。「コピー」を押した時点で自動的に投稿済みへ変更され、投稿済みでは「再コピー」と表示されます。独立した「投稿済みにする」ボタンはありません。

## 開発

- 作業ブランチ: `rebuild/xpostplus-v1`
- `main` へ直接コミットしないでください。
- フレームワークは使用していません。
