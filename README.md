# XPostPlus

X（旧Twitter）へ投稿する記事をAPI・RSSから取得し、ポスト文を簡単に作成・管理する管理者専用Webアプリです。Xへの自動投稿は行いません。

## 必要環境

- PHP 8.1以上
- MariaDB 10.4以上（MySQL 8系でも利用可能）
- PHP拡張: PDO MySQL、Sodium、SimpleXML、Fileinfo、mbstring
- HTTPS

Webサーバーの公開ディレクトリは `public` に設定してください。サブディレクトリ公開にも対応しています。

## 初回セットアップ

1. `rebuild/xpostplus-v1` のファイルをサーバーへ配置します。
2. MariaDB側で空のデータベースと接続ユーザーを作成します。
3. ブラウザで開くと「MariaDB初期設定」が表示されます。
4. DB名・DBユーザー名・DBパスワードを入力し、「接続テストして保存」を押します。
5. 接続成功後、不足テーブル・カラム・インデックスが自動作成されます。SQLの手動実行は不要です。
6. 初期ID `admin`、初期パスワード `password` でログインします。

初回ログイン後のパスワード強制変更はありません。必要に応じて設定画面から変更できます。

DB設定は `storage/config/database.json` に保存されます。Webサーバーから `storage` を直接公開しないでください。
接続先は `localhost:3306` に固定されているため、ホストとポートの入力は不要です。

## メニュー

- ダッシュボード
- API設定
  - 各サイト設定
  - APIテンプレート
- RSS設定
  - RSS登録
  - RSSテンプレート
- 投稿管理
- 設定
- ログアウト

## 対応API

APIメニューの各設定画面へ次の情報を保存してから接続テストを行います。認証情報の暗号化キーは初回保存時に自動生成されます。

- FANZA: API ID、アフィリエイトID
- DUGA: アプリケーションID、代理店ID、バナーID
- SOKUMIRU: API KEY、アフィリエイトID

各APIはキーワード、取得件数、並び順、開始日、終了日を指定できます。取得する内容はタイトル、記事URL、サンプル画像、サンプル動画URLです。テンプレートはFANZA・DUGA・SOKUMIRUごとに最大3件まで登録できます。

## 操作の流れ

1. 投稿管理で「API取得」または「RSS取得」を選びます。
2. 取得条件を入力し、「取得」ボタンを押します。
3. 必要な記事を選び、テンプレートからポストを作成します。
4. ポスト文をコピーしてXへ投稿します。

cronは使用しません。API・RSSともに、管理画面の取得ボタンを押したときだけ記事を取得します。

## 投稿管理

API・RSSで作成したポストを一か所で管理します。「コピー」を押した時点で自動的に投稿済みへ変更され、投稿済みでは「再コピー」と表示されます。独立した「投稿済みにする」ボタンはありません。

取得後に使用しなかった記事は、チェックボックスで選択して一括削除できます。表示件数変更と一括削除は「一覧の操作」を開いたときだけ表示されます。

## 開発

- `main` へ直接コミットしないでください。
- フレームワークは使用していません。
